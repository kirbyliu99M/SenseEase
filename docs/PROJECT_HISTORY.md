## 3. Recurring code-failure lessons

- **Edge-trigger anything "once per event" (EM1).** Root cause of the `MaybePersistProfileSnapshot`/`BuildProfileSnapshot` storm: per-tick severe-strike → ~15Hz disk rewrites + event-log flood. Fix = throttled edge-triggered merge-over-disk under one lock. (ALPHA_HANDOVER, CodeReview-Opus4.8)
- **Read-modify-write under lock for multi-writer files (EM2).** Engine snapshot Save silently wiped `longitudinal_observations`; non-atomic profile-snapshot write race persists. (ALPHA_HANDOVER, CodeReview-Opus4.8, HABITUATION_ADJUSTMENT_PLAN)
- **Over-broad reset is the C5 pattern.** Split `Reset` into `ResetPostCalibration` vs `ResetTransientState`; never let a transient/shader reset zero `_offset`. (ALPHA_BACKLOG, ALPHA_HANDOVER)
- **Duplicate constants need a parity test or single source (C3).** (ALPHA_HANDOVER) — band-threshold logic has a single source of truth `TierColorPalette.BandForTier`; converters must never duplicate the ≤5/6-7/8-10 thresholds. (archive/M5_IMPLEMENTATION_PLAN)
- **IEventLogStore → dashboard subscribe gap (M1).** When adding an `IEventLogStore` category, verify the dashboard `ObservableCollection` subscribes. The `IEventLogStore.Appended` event (fix `77163d9`) mirrors every store append into the dashboard table — without it Habituation/M1 events are written but invisible. (ALPHA_HANDOVER, POPUP-AND-HABITUATION-INTEGRATION-AUDIT)
- **OneWay bindings on read-only state.** Read-only `ProgressBar.Value`/`VimsTier` bindings must be `Mode=OneWay`; `TwoWay` on read-only `VimsTier` crashes startup. (DEBUGGING, archive/M5_IMPLEMENTATION_PLAN)
- **App.Resources smoke-test trap.** Theme tokens must merge **view-locally** into each Window/UserControl `.Resources` via `pack://` URI — NEVER `App.Resources` — because `MainWindowSmokeTests` boots a bare `new Application()` that never loads `App.xaml`. (UIUX_UPGRADE_PLAN, design/DESIGN_SYSTEM, design/LOCKED_DIRECTION_ALPHA1, archive/M5_IMPLEMENTATION_PLAN)
- **Test anti-pattern.** Tests asserting concrete return types (`IsType<X>`) instead of the library/OS contract; unit tests cannot model a library↔OS handshake state. (QA-AND-TIERING)
- **Empirical > inferred (L18).** For any fact-shaped decision (sensor sign / perf / hotfix-status / device) use CSV-instrumented diagnose runs; the pitch-sign was demo-verified but day-1 wrong (L16). (POPUP-AND-HABITUATION-INTEGRATION-AUDIT)
- **Soften-seam discipline.** `ApplyUserFeedback(int fovDelta, bool isDeliberatePreference=false)`; guard `if (fovDelta<0 && !isDeliberatePreference) _habituation.NotifyDiscomfort(...)`. The deliberate path never calls `NotifyDiscomfort` (Q4.5 preserved by construction). Use a literal "more protection" control, NOT the coarse `Intent != ReportDiscomfort` gate (avoids silencing a genuine complaint if NLU labels drift). Discomfort ramp is a COMPLAINT path that erodes `_offset` — must never share a code path with deliberate preference. (design/alpha1-detail/soften-engine-seam, design/alpha1-detail/review-honesty-ux, ALPHA_AUDIT_FINDINGS AF-1)
- **Sacred `_offset` (D3).** "Reset visual settings" (transient) must stay distinct from "Delete all my data"; neither may zero `_offset`. (design/VISUAL_SPEC, archive/M5_IMPLEMENTATION_PLAN)

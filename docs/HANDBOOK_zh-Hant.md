# SenseEase 使用手冊（Pre-Alpha 測試版）

歡迎來幫忙測試 SenseEase！

這份手冊會帶你跑過所有功能,讓你知道每個畫面是做什麼用的,
避免測試時誤會某些行為。整份大概 5 分鐘就可以讀完。
**真的有問題再回報就好,功能不熟悉造成的「我以為它應該⋯」不算 bug,
照著這份手冊走一遍通常就能對齊期待。**

---

## 1. 這個 App 是什麼?

SenseEase 是一個**「螢幕視覺舒適輔助工具」**,
目的在減輕長時間看螢幕造成的視覺暈動症 (VIMS)、眼睛疲勞、
還有快速畫面變化(例如 FPV 影片、捲動清單、激烈遊戲)引起的不舒服。

它的核心做法是:

- **持續偵測螢幕上的光流變化** (你看到的畫面有多劇烈)
- **依據累積壓力動態調整 FOV(視野遮罩)**,把週邊變化壓低
- **AI Assistant 可以對話,協助微調舒適度**
- **頭部追蹤** 讓 FOV 遮罩跟著你的頭部位置移動,
  讓你的視線焦點永遠落在最舒服的中心區域

整套是 **本機運行 (offline)**,你的影像、語音、對話都不會上傳。

## 2. 介面導覽 (各視窗是做什麼的)

App 啟動後你會看到以下幾個東西。請先了解一下,測試時才不會誤會。

| 介面 | 在哪 | 做什麼 |
|---|---|---|
| **主控視窗 (Main Console)** | 雙擊 app 後出現的主視窗 | 切換頁籤、查看資料、設定 |
| **儀表板 / Dashboard 頁籤** | 主視窗第一頁 | 即時數值、Demo 控制、事件紀錄 |
| **護眼儀表板 / Eye Protection** | 主視窗頁籤 | 詳細的護眼指標 |
| **AI Assistant 頁籤** | 主視窗頁籤 | 聊天機器人 (本機 Mistral 3B) |
| **設定 / Settings 頁籤** | 主視窗最後一頁 | 開關各項功能 |
| **頂部 Bar** | 螢幕上方一條細長的條 | 顯示 VIMS 壓力等級 (灰/黃/紅) |
| **通知卡片 (Notification Card)** | 點 Bar 後彈出的小視窗 | 快速回報不適、開省電、開啟保護 |
| **Overlay (FOV 遮罩)** | 覆蓋整個螢幕的半透明遮罩 | 用「向中心聚焦」減輕週邊視覺壓力 |
| **系統匣 (Tray) 圖示** | 螢幕右下系統匣 | 顯示目前狀態 + 右鍵選單 |

⚠ **特別提醒**:

- **Bar 的尺寸會隨滑鼠靠近而變大**,這是「方便點擊」的設計,
  **不是頭部追蹤跟著滑鼠**。
- **頭部追蹤只透過 webcam 來判斷**,從不讀取滑鼠位置。
- 如果頭部追蹤「沒反應」,通常是 webcam 沒授權、或頭部追蹤沒開,
  不是程式碼把它接到滑鼠了 (沒這回事)。

## 3. 開啟你要測的功能 (設定頁籤)

### Step 1: 打開「設定 / Settings」頁籤

主視窗最後一頁。

### Step 2: 開啟以下選項

至少建議打開:

- **☑ 啟用頭部追蹤 / Enable Head Tracking**
  - 需要 webcam 權限。第一次開啟時 Windows 可能會問你是否允許 SenseEase 使用相機,**請選「允許」**。
- **☑ Bar + Tray 顏色顯示 / BarTrayColorEnabled** (預設關閉)
  - 開啟後 Bar 和系統匣會依照 VIMS 壓力等級顯示灰/黃/紅。
- **(其他選項依你想測的功能自由勾選)**

### Step 3: 把設定關掉並**重新啟動 App**

頭部追蹤這類功能需要重啟才會載入 (sidecar 在啟動時才會跑起來)。

> 重啟方式: 右下系統匣圖示按右鍵 → 「離開 / Quit」→ 重新開啟 App。

## 4. 測試頭部追蹤 (Overlay「持續顯示」模式)

頭部追蹤啟用後,FOV 遮罩會跟著你的臉部位置移動。
要看清楚這個效果,最簡單的方法是**把 Overlay 設成持續顯示**。

### 操作步驟

1. 啟動 App,確認 Bar 有出現在螢幕上方。
2. 點 Bar → 通知卡片彈出。
3. 卡片上有個 **「啟動保護 / Engage Protection」** 按鈕,按下去。
   → Overlay 會出現,即使沒有 VIMS 壓力也會持續顯示。
4. **動動你的頭** (左右、上下都試試),
   → FOV 遮罩的「清晰中心區域」應該跟著你的頭移動。
5. 如果遮罩動了 = 頭部追蹤正常運作 ✓
6. 如果遮罩**一直停在螢幕正中央不動** = webcam 沒接上,或追蹤沒啟用。
   請檢查:
   - 設定中「啟用頭部追蹤」是否打勾
   - Windows 設定 → 隱私 → 相機 → SenseEase 是否被允許
   - 重啟 App 看看

### 順帶測試的東西

- 頭轉左 → FOV 中心也往左 ✓
- 頭轉右 → 中心往右 ✓
- 頭低下 → 中心往下 ✓
- 把臉從相機畫面中移出 → 中心**回到正中央** (這是設計上的安全機制)

---

## 5. 測完頭部追蹤,記得**關掉 Overlay 持續模式**

測完後,如果 Overlay 一直開著會干擾正常使用 (整個螢幕都罩著半透明)。
**請務必關掉持續模式**:

- 方法 1: 點 Bar → 通知卡片 → 再按一次 **「啟動保護」** 切回自動模式。
- 方法 2: 系統匣圖示右鍵 → 「隱藏 Overlay」。

之後 Overlay 會回到「**只有 VIMS 壓力達到閾值時才自動出現**」的正常模式。

## 6. 用 Calibration / 示範影片測試

Calibration (校準) 會跑一段 **FPV 飛行影片** (113 MB,bundle 在安裝包裡),
模擬激烈的螢幕變化,觀察你看的時候的不適程度,並協助調整你的個人設定檔。

### 操作步驟

1. 切到「儀表板 / Dashboard」頁籤。
2. 找到 **「Calibration & Demo」按鈕** (藍色 Primary 按鈕)。
3. 按下去,FPV 影片會在新視窗開始播放。
4. **看完整段** (約 1 分鐘),期間如果有任何不適,
   可以使用通知卡片上的「輕微 / 中等 / 明顯 / 嚴重」按鈕回報。
5. 影片結束後,AI Assistant 可能會主動提議調整你的設定檔,
   例如:「我建議切換到 SENSITIVE profile」。

### 預期觀察

- 影片播放時,Bar 的壓力等級會上升 (灰 → 黃 → 可能到紅)
- 如果壓力夠高,FOV Overlay 會自動跳出來保護你 (這就是它的本職)
- 結束後 Bar 會慢慢降回灰色

## 7. AI Assistant 對話測試

切到「AI Assistant」頁籤,跟本機跑的 Mistral 3B 模型對話。

### 注意事項 (★ 重要)

- **首次載入需要 30-120 秒** (NVIDIA GPU ~10 秒、CPU/iGPU ~60-120 秒)
  載入中視窗會顯示 "Loading Ministral 3B…"。
  **請耐心等待,不是 App 卡住了。**
- 載入完成後狀態文字會變成 "Ministral 3B ready"。
- 在 Intel iGPU (例如 Iris Xe) 上,每則回覆需要 5-30 秒,屬正常。
- 在 NVIDIA GPU 上,每則回覆大約 1-2 秒。

### 建議測試的對話

試試以下訊息:

```
你好,請介紹自己
```

```
我看螢幕看得頭暈,可以幫我嗎?
```

```
我想切換到比較敏感的 profile
```

```
請把敏感度降低一點
```

AI 可能會:
- 給你建議
- 主動提議切換 profile (在通知卡片上顯示「接受 / 稍後 / 拒絕」)
- 記錄你的偏好

### 也可以試試

- 點下方的「Clear」按鈕清空對話。
- 「清空後應該會看到歡迎詞重新出現」(這是設計上的)。

## 8. 實際使用情境測試

請把 App **開著 30-60 分鐘**,當作平常上網/工作那樣使用,例如:

- **看 YouTube 影片** (特別是運動、遊戲、FPV 等畫面變化大的)
- **滑社群網站** (Twitter、IG 快速捲動 feed)
- **玩遊戲或看 Twitch 直播**
- **長時間閱讀文件** (測試靜態畫面下 App 是否乖乖待著不亂動)

### 預期觀察

- 看快速畫面 → Bar 漸漸從灰變黃變紅 → FOV Overlay 自動出現保護
- 畫面靜止下來 → 壓力慢慢回落 → Overlay 自動隱藏
- 系統匣圖示顏色 (如果在設定打開了 BarTrayColorEnabled) 跟著等級變
- 頭部追蹤一直跟著你的頭部位置

### 不應該發生的事

- App 突然崩潰 / 視窗消失
- Overlay 卡住下不來,即使壓力已經回落
- Bar 或 Tray 顯示錯誤的顏色 (例如壓力很高還是灰色)
- 影片播放卡頓很嚴重
- AI 回覆超過 3 分鐘還沒出來

如果上面有任何一項發生,**請回報並附上以下 logs**:

```powershell
# 在 PowerShell 執行,只會打包診斷檔案(不含個人資料)
& "$env:LOCALAPPDATA\Programs\SenseEase\scripts\collect-logs.ps1"
```

這會在桌面產生一個 zip,內容只有 crash log、診斷資料夾
（`%LOCALAPPDATA%\SenseEase\diag`）和 llama-server log。
**不包含**你的對話紀錄、校準問答、AI 模型 trace、舒適設定檔或使用量統計。

把這個 zip 連同你的問題描述傳給我們。

## 9. 解除安裝（你的資料由你決定）

解除安裝 SenseEase 時，解除安裝程式會詢問是否要**一併刪除你的個人資料**
（設定、對話與校正紀錄、個人化模型，以及 `%LOCALAPPDATA%\SenseEase` 下的記錄檔）。

- 選「是」可乾淨移除（測試結束後建議）。
- 選「否」可保留資料供日後重新安裝。

一般的重新安裝永遠不會刪除你的資料；只有這個明確的選項（H25）才會。
你也可以在「設定 → 資料與隱私」用「清除所有資料並重設」按鈕（H24）清除個人化模型，
但會保留你的校正設定檔。
